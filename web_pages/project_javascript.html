クイズ アプリ

ソース コード

・React + ASP.NET Core MVC + SQL Server
・JavaScript初心者、中級者向けのクイズ問題を選択問題として表記
・Emailでユーザー登録又は、ゲストアカウントでクイズの開始が可能
・タイマーでクイズの実施時間を記録される
・クイズ完了後の答え合わせが表示される

SNSダッシュボード

・各ソーシャルメディアのプラットフォームのフォロワー数を表示する
（数値は全てスタティック、アカウント名も偽名）
・Figmaデザイン書類に基づいて組み上げたサイト
・BEM（Block Element Modifier）モデルで構成されたCSS
・SASSとBEMを使用して、各コンポーネントの管理をしやすくする
・アクセシビリティを意識したコードで構成
- キーボード操作、スクリーンリーダー使用者に対応
・ページのデフォルトカラーがOSを参照
・ダーク/ライト モードの色切替可能
・Gulp を使用してSASSをCSSにコンパイル
・カーソルでカードをハイライト
・複数の解像度に対応されたレイアウト


Amazon ECサイトの基盤プロジェクト

・商品の個数を選択して、カートに追加
（デフォルトでカートに２アイテムが入っている）
・右上のカートが更新され、カートアイコンを選択して購入画面に進む
・デリバリーオプションによって配達予定日時/合計価格が更新される


じゃんけんゲーム

・グー、チョキ、パーのアイコンを選択
・CPUがランダムで選択して勝負が決まる
・スコアは表示され、保存される
・スコラリセット可能
・自動プレイで１秒ごとに起動する
