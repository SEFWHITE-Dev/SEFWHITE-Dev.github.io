JavaScript プロジェクトリスト

・SNSダッシュボード

- 各ソーシャルメディアのプラットフォームのフォロワー数を表示する
（数値は全てスタティック、アカウント名も偽名）
- BEM（Block Element Modifier）モデルで構成されたCSS
- SASSとBEMを使用して、各コンポーネントの管理をしやすくする
- ページのデフォルトカラーがOSを参照
- ダーク/ライト モードの色切替可能
- Gulp を使用してSASSをCSSにコンパイル


・Amazon ECサイトの基盤プロジェクト

- 商品の個数を選択して、カートに追加
（デフォルトでカートに２アイテムが入っている）
- 右上のカートが更新され、カートアイコンを選択して購入画面に進む
- デリバリーオプションによって配達予定日時/合計価格が更新される


・じゃんけんゲーム

- グー、チョキ、パーのアイコンを選択
- CPUがランダムで選択して勝負が決まる
- スコアは表示され、保存される
- スコラリセット可能
- 自動プレイで１秒ごとに起動する


・タスク管理リスト

- タスク名をインプット
- 日付をインプット
- タスクの追加、削除が可能
